## Overview

Updating the CSS allows you to change the UI of the components to meet your needs.
This section guides you through an example of updating the look of buttons.
Note that the process can update any HTML tag from within SuperTokens components.

## Before you start

:::warning
This example is relevant only if you use the prebuilt UI components.
:::

---

## Global style changes

First, open the website at `/auth`. The Sign-in widget should show up. Use the browser console to find out the class name that you'd like to overwrite.

<img alt="Inspecting submit button in prebuilt form" width="500px" src="/docs/img/emailpassword/inspect-button.png" />

<img alt="Highlighting attribute for customization" width="500px" src="/docs/img/emailpassword/inspect-button-2.png" />

Each stylable component contains `data-supertokens` attributes (in this example `data-supertokens="button"`). 

Let's customize elements with the `button` attribute. The syntax for styling is plain CSS.

<Tabs group="frontend-prebuilt-ui">
<Tab title="Reactjs" value="reactjs">

```tsx {9,10,11,12,13,14,15,16}
import SuperTokens from "supertokens-auth-react";

SuperTokens.init({
    appInfo: {
        apiDomain: "...",
        appName: "...",
        websiteDomain: "..."
    },
    style: `
        [data-supertokens~=button] {
            background-color: #252571;
            border: 0px;
            width: 30%;
            margin: 0 auto;
        }
    `,
    recipeList: [ /* ... */]
});
```
</Tab>

<Tab title="Angular" value="angular">

```tsx {9,10,11,12,13,14,15,16}
// this goes in the auth route config of your frontend app (once the pre-built UI script has been loaded)

supertokensUIInit({
    appInfo: {
        apiDomain: "...",
        appName: "...",
        websiteDomain: "..."
    },
    style: `
        [data-supertokens~=button] {
            background-color: #252571;
            border: 0px;
            width: 30%;
            margin: 0 auto;
        }
    `,
    recipeList: [ /* ... */]
});
```
</Tab>
</Tabs>

### Changing fonts

By default, SuperTokens uses the `Arial` font. The best way to override this is to add a `font-family` styling to the `container` component in the recipe configuration.

<Tabs group="frontend-prebuilt-ui">
<Tab title="Reactjs" value="reactjs">

```tsx
import SuperTokens from "supertokens-auth-react";

SuperTokens.init({
    appInfo: {
        apiDomain: "...",
        appName: "...",
        websiteDomain: "..."
    },
    style: `
        [data-supertokens~=container] {
            font-family: cursive;
        }
    `,
    recipeList: [ /* ... */]
});
```
</Tab>

<Tab title="Angular" value="angular">

```tsx
            font-family: cursive;
        }
    `,
    recipeList: [ /* ... */]
});
```
</Tab>

### Using media queries

You may want to have different CSS for different `viewports`. This can happen via media queries like this:

<Tabs group="frontend-prebuilt-ui">
<Tab title="Reactjs" value="reactjs">

```tsx
import SuperTokens from "supertokens-auth-react";

SuperTokens.init({
    appInfo: {
        apiDomain: "...",
        appName: "...",
        websiteDomain: "...",
    },
    style: `
        [data-supertokens~=button] {
            background-color: #252571;
            border: 0px;
            width: 30%;
            margin: 0 auto;
        }

        @media (max-width: 440px) {
            [data-supertokens~=button] {
                width: 90%;
            }
        }
    `,
    recipeList: [ /* ... */],
});
```
</Tab>

<Tab title="Angular" value="angular">

```tsx
// this goes in the auth route config of your frontend app (once the pre-built UI script has been loaded)

supertokensUIInit({
    appInfo: {
        apiDomain: "...",
        appName: "...",
        websiteDomain: "...",
    },
    style: `
        [data-supertokens~=button] {
            background-color: #252571;
            border: 0px;
            width: 30%;
            margin: 0 auto;
        }

        @media (max-width: 440px) {
            [data-supertokens~=button] {
                width: 90%;
            }
        }
    `,
    recipeList: [ /* ... */],
});
```
</Tab>

## Customize the password reset forms

### Send password reset email form

This form appears when the user clicks on "forgot password" in the sign in form.

<Tabs group="frontend-prebuilt-ui">
<Tab title="Reactjs" value="reactjs">

```tsx {13,14,15,16,17}
import SuperTokens from "supertokens-auth-react";
import EmailPassword from "supertokens-auth-react/recipe/emailpassword";
import Session from "supertokens-auth-react/recipe/session";

SuperTokens.init({
    appInfo: {
        apiDomain: "...",
        appName: "...",
        websiteDomain: "...",
    },
	recipeList: [
        EmailPassword.init({
            resetPasswordUsingTokenFeature: {
                enterEmailForm: {
                    style: ` ... `
                }
            }
        }), 
        Session.init()
	]
});
```
</Tab>

<Tab title="Angular" value="angular">

```tsx {11,12,13,14,15}
// this goes in the auth route config of your frontend app (once the pre-built UI script has been loaded)

supertokensUIInit({
    appInfo: {
        apiDomain: "...",
        appName: "...",
        websiteDomain: "...",
    },
	recipeList: [
        supertokensUIEmailPassword.init({
            resetPasswordUsingTokenFeature: {
                enterEmailForm: {
                    style: ` ... `
                }
            }
        }), 
        supertokensUISession.init()
	]
});
```
</Tab>
</Tabs>
