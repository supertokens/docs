## Overview

The fastest way to run a quick demo of **SuperTokens** is to use the CLI to generate an example application. You will get a quick understanding of the authentication experience and the overall project setup.

<ExampleAppForm />

## Project Structure

The command creates a new folder based on the application name you specify. Inside it, you will find a project configured to support an authentication flow based on the recipe you chose.
